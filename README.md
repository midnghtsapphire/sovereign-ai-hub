# Sovereign AI Hub

Marketing site for a privacy-first, local-first AI product concept (“Your AI. Unfiltered.”). This repo ships a Vite + React + Tailwind landing page with sections for features, requirements, pricing, and FAQ.

## What this repo does (today)

- Hosts a production-ready landing page UI (single-page + 404 route).
- Provides a baseline test/build/lint setup (`vitest`, Vite build, ESLint).
- Can be deployed directly to Vercel as a fully functioning marketing webpage.

## Research engine recommendations

If this repo is extended into a live research workflow, use a layered retrieval approach:

1. **Web search API** (fresh discovery): Tavily or SerpAPI for current sources.
2. **Crawling/indexing** (artifact collection): Firecrawl or Jina AI Reader for page extraction.
3. **RAG/vector layer** (grounded answers): Postgres + pgvector or Qdrant for citation-backed retrieval.
4. **Evaluation/guardrails** (quality and safety): promptfoo or DeepEval for regression checks.

This keeps the site production-simple now while giving a clear path to a research-engine backend.

## Assets and artifacts

- Static web assets: `public/` (`favicon.ico`, `robots.txt`, and `placeholder.svg` as a replaceable template asset)
- App source artifacts: `src/` (pages, components, styles)
- Build artifact: `dist/` (generated by `npm run build`, not committed)
- Delivery docs: `DEPLOYMENT_GUIDE.md`, `GO_TO_MARKET.md`, `SECURITY.md`, `CHANGELOG.md`

## Local development

```sh
npm install
npm run dev
```

## Validation

```sh
npm test
npm run build
npm run lint
```

`npm test` runs the Vitest suite in `src/test/`.
