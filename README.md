# Sovereign AI Hub

Marketing site for a privacy-first, local-first AI product concept (“Your AI. Unfiltered.”). This repo ships a Vite + React + Tailwind landing page with sections for features, requirements, pricing, and FAQ.

## What this repo does (today)

- Hosts a production-ready landing page UI (single-page + 404 route).
- Provides a baseline test/build/lint setup (`vitest`, Vite build, ESLint).
- Can be deployed directly to Vercel as a fully functioning marketing webpage.

## Research engine recommendations

If this repo is extended into a live research workflow, use a layered retrieval approach:

1. **Web search API** (fresh discovery): Tavily, SerpAPI, Exa.
2. **Crawling/indexing** (artifact collection): Firecrawl, Jina AI Reader, Bright Data.
3. **RAG/vector layer** (grounded answers): Postgres + pgvector, Qdrant, Weaviate, Pinecone.
4. **Orchestration** (routing/tools): LangGraph, LlamaIndex, DSPy.
5. **Evaluation/guardrails** (quality and safety): promptfoo, DeepEval, RAGAS.

### Research engine stack suggestions

- **Lean OSS stack**: Tavily + Firecrawl + pgvector + LangGraph + promptfoo.
- **Managed scale stack**: SerpAPI + Bright Data + Pinecone + LlamaIndex + DeepEval.
- **Compliance-first stack**: Exa + Jina + Qdrant self-hosted + LangGraph + RAGAS.

### Suggested research artifacts

- Source registry (`sources.json`) with license, freshness, and trust score metadata.
- Research snapshots (`/artifacts/research/*.md`) with citations and extraction timestamps.
- Evaluation reports (`/artifacts/evals/*.json`) for retrieval/answer quality drift.
- Weekly recommendations brief (`/artifacts/briefs/*.md`) for product and GTM decisions.

This keeps the site production-simple now while giving a clear path to a research-engine backend.
